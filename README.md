# Mamaearth Returns & Growth Intelligence Pipeline

A reproducible capstone project that connects a SQLite relational layer, a pandas cleaning and EDA layer, and a Gemini-powered business narrative with an offline fallback.

## Requirements

Python 3.10+ is recommended. Install packages from the repository root:

```bash
python -m pip install -r requirements.txt
```

## Reproduce the Python and GenAI layers

Run commands from the repository root, in this order:

1. Generate cleaned metrics, analysis CSVs, and the verified JSON findings:

   ```bash
   python analysis/clean_and_eda.py
   ```

2. Generate both required charts:

   ```bash
   python analysis/visualize.py
   ```

3. Generate the SCR narrative and run the numeric accuracy check:

   ```bash
   python narrator/generate_narrative.py
   ```

The first script reads source CSVs from `data/`, never edits them, and writes computed findings to `narrator/findings.json`. The narrative script reads those findings and writes `narrator/sample_output.txt`.

## Optional Gemini API

The project can run without an API key. If you want Gemini-generated prose, set `GEMINI_API_KEY` in your local environment using a Google AI Studio key, then rerun step 3. Never commit the key to GitHub. If the key is missing or the API call fails, a local template-based SCR narrative is generated instead.

PowerShell example for the current terminal session:

```powershell
$env:GEMINI_API_KEY = "YOUR_KEY_HERE"
python narrator/generate_narrative.py
```

Do not paste your key into a notebook or source file, and do not share it in screenshots.

## SQLite layer

The SQL files are included under `sql/`. The seed script is designed to load the provided rows after schema creation. The exact import method depends on the SQLite CLI or GUI being used. Verify row counts after loading: customers 45, products 16, orders 180. The report queries in `sql/reports.sql` are designed for the raw tables; run the schema and seed before reports.

## Analysis definitions and limitations

- Discounted order value = quantity × product price × (1 − discount percentage / 100).
- Missing discounts are treated as 0%; missing ratings are imputed with the median in the Python cleaning layer.
- Potential duplicates are detected using customer, product, order date, and quantity; the first matching row is retained.
- Quantity outliers are flagged using the 1.5×IQR rule and are not deleted. The monthly corrected trend excludes only flagged rows for comparison.
- Retained order value excludes orders marked returned. It is an analytical measure and is not verified accounting revenue or refund reconciliation.
- Return-rate differences are descriptive associations, not proof of causation.
- The narrator checks five figures generated by the analysis against the output narrative. Any failed check should be reviewed before submission.
